# 2026-10-31-map-picking-and-ui-fixes

## 做了什么

八项修复，围绕「地图选点」和三处界面细节：

1. **商户端商品弹窗**：「地图位置」整块对 `goods`（农产文创）隐藏——实物发货没有
   「在哪儿」的问题；研学 / 民宿 / 农事体验仍显示。保存时 `goods` 分类强制把
   `mapX/mapY` 写成 `null`，避免历史残留坐标。
2. **地图选点交互重做**（三端共用的 `assets/js/village-map.js`）：
   点击热区从 `.vmap-stage` 上移到根 `.vmap`，整个地图容器都能点；
   新增 `pickable` 守卫（只读地图不再误触发 `pick`）；
   已标注时**再点同一个点取消**，也可以直接点准星取消（新增 `@unpick` 事件与 `cancelPick()`）。
3. **删除裸坐标显示**：三端四处「地图位置」块里的 `X 200 / Y 240` 标签与
   「清除位置」按钮全部去掉，改成「已标注位置 / 还没标注位置」的状态标签。
4. **管理员端商品位置**：确认保存链路本身是通的（`PUT /api/admin/products/{id}`
   带 `mapX/mapY`，回读一致、置 `null` 也一致），问题在前端点选交互，随第 2 条修复。
   点位 / 活动编辑弹窗同步改造。
5. **行程规划页**左上角新增返回按钮（和其他页面同款 `.back` 样式）。
6. **AI 文旅助手**返回按钮从提示卡片内部移到卡片外、页面左上角。
7. **「我的」页**最下方「修改密码 / 退出登录」两个通栏按钮之间加 12px 间距
   （原来 CSS 里根本没有 `.mine-actions` 规则，两个按钮上下贴死）。
8. **favicon**：生成物改名为 `favicon-datong.svg`，四端页面引用换新路径并带 `?v=2`，
   删掉旧 `favicon.svg`。

## 为什么这么改

**「地图选点没反应」的真实原因有两层，都不是后端问题：**

- 第一层是**热区太小**：`.vmap-stage` 按底图比例缩放后只有 400px 宽，而容器 540px，
  左右各留 70px 空白。`@click` 原来绑在 stage 上，用户点在空白区就什么都不发生。
  另外编辑弹窗内容太高（实测 1141px > 900px 视口），地图落在首屏之外、弹窗又滚不动，
  用户根本滚不到地图那里。→ 热区上移 + 给 `.el-dialog__body` 加 `max-height:74vh` 滚动。
- 第二层是 **Vue 2 响应式陷阱**：新增商品时 `form` 是字面量对象，本来没有
  `mapX/mapY` 这两个键，`onPickPos` 里直接 `this.form.mapX = ...` 赋值，
  Vue 2 侦测不到「后来新加的属性」→ 准星不出现、`hasMapPos` 不刷新，
  看起来就是「点了没反应」。→ 全部改用 `this.$set(this.form, 'mapX', ...)`。

**favicon 是浏览器缓存问题，不是代码问题。** 源码里的 `favicon.svg` 早就是红色
`#C0392B`，用户看到的绿色战旗村图标来自浏览器对 `127.0.0.1:8080` 这个 origin 的
favicon 强缓存（favicon 缓存极粘，换内容不换路径往往几个月不刷新）。
**唯一可靠解法是换文件名**，所以改成 `favicon-datong.svg` 并加 `?v=2` 双保险。

**为什么 `goods` 分类不显示地图**：农产文创是实物快递发货，位置对它没有业务含义；
强行让商家标注只会产生一堆无意义坐标，也让地图页多出噪声标记。研学 / 民宿 /
农事体验是「到村去哪儿」的场景，才需要位置。

**为什么把「清除位置」按钮删掉**：原来「X 200 / Y 240 + 清除位置」这套 UI 对非技术
用户没有意义（数字是内部虚拟坐标系），而且「点地图选点」和「点按钮清除」是两套
心智模型。改成「再点同一个点取消」后，选点和取消都在同一个动作里完成，也不需要
再解释坐标系是什么。

## 遗留

- 虚拟地图坐标系是「画布坐标」而不是真实经纬度（0–1000 / 0–700），底图换版时
  已有点位需要人工复核位置是否仍然合理。这是刻意的取舍：断网可用、不依赖地图服务商。
- 编辑弹窗里地图仍是固定 280–300px 高，若后续再加图集行数，需要一并调整
  `.el-dialog__body` 的 `max-height` 比例。
- `favicon` 用换文件名绕过缓存，若以后还要换图标，建议继续递增版本号（`favicon-datong-v2.svg`）。
