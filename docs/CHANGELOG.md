# 更新日志

本文件面向**使用者与后续维护者**，只写「用户能感知到什么变化」。
工程细节、排查过程与自检摘要写在 `docs/worklog/` 下的工作日志里。

格式约定（与 AGENTS.md 第八节配套）：

- `## 未发布` 收集已经进仓库、但还没打版本号的内容；
- 发版时把「未发布」整块挪到 `## vX.Y.Z — YYYY-MM-DD` 下；
- 每条一句话，动词开头，写清「哪一端 / 发生了什么变化」；
- 不兼容变化必须单独用 **⚠ 不兼容** 标出，并写清迁移方式。

## 未发布

### 新增

- 游客端新增**独立聊天页**：左侧会话列表可切换多个商家，右侧消息流每条带双方头像与发送时间。
- 游客端新增**大同村虚拟地图**整页：覆盖点位打卡、研学课程、民宿住宿、农事体验、农产文创、村内活动共 48 个位置，支持滚轮/双指缩放、拖拽平移、按类别筛选、点标记看详情并跳转。
- 点位详情页新增「在村里的位置」内嵌小地图；活动详情页新增举办位置地图。
- 商城新增 8 个商品（庭院家庭套房、星空营地帐篷位、黄花田农事耕作体验、古法榨油体验课、打谷场秋收体验、桑干河湿地自然观察课、古堡烽台历史研学、铜艺錾花手作课），研学 / 民宿 / 农事体验三类商品更完整。
- 点位打卡详情新增印章徽章（已打卡点位在选项卡卡片与详情页都显示朱砂印章）。
- 活动详情新增图集轮播（≥3 张）与「活动亮点」板块。
- 管理员「服务器管理 → 个性化设置」补全：四个主题卡片（朱砂 / 青瓷 / 墨夜 / 靛蓝）+ 预览说明，可一键切换。
- 管理员商品、点位、活动编辑弹窗新增**图集编辑器**与**地图选点**。
- 商户端商品编辑弹窗新增**图集编辑器**与**地图选点**（研学 / 民宿 / 农事体验类建议标注位置）。
- 游客端页面切换新增过渡动画（视图淡入上移 + 卡片阶梯入场，遵循 `prefers-reduced-motion`）。
- 商户端「地图位置」按商品类型区分：农产文创（实物发货）不显示地图，研学 / 民宿 / 农事体验保留选点。
- 站点图标换新：`assets/img/favicon-datong.svg`（红底「大」字 + 金点），四端页面统一引用。
