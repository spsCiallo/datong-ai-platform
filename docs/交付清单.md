# 大同村农商文旅智慧平台 · 交付清单

> 本轮由 zhanqi-ai-platform（战旗村项目）重构而来。
> 后端架构、接口、数据表、权限与部署方式沿用原项目，保证可运行、接口兼容；
> 游客端合并为一套响应式界面；前端视觉全面换新；演示数据重写为大同村内容。

## 一、复用清单（改名后原样沿用）

| 范畴 | 内容 |
| --- | --- |
| 后端架构 | SpringBoot 3.3.5 / Java 17 单体 fat jar；Db+Tables 白名单数据门面；R/ApiException 统一响应；AuthInterceptor + @RequireRole 会话鉴权；DatabaseBootstrap 幂等自举；PortGuard 端口守卫；DiscoveryService UDP 发现 |

## 四、接口适配说明

本轮**不改任何 REST 路径、请求/响应字段、角色权限与订单状态机**。
三端页面全部按既有契约对接，重点保证：

- 登录态按端隔离（localStorage `datong.<ns>.token`）
- 购物车只有 goods 可加购；混合结算 items 逐项带预约参数
- 商家拒绝 → 买家同意关闭 / 继续协商（`/buyer-decision`）
- 完成订单唯一入口是买家 `/receive`（与结算同动作、幂等）
- 活动预约与商品订单分离
- AI 未命中明确说明，不编造

前端 JS 公共对象：`window.DT`（请求）、`DTTheme`、`DTSpeech`、`DTProfile`、`DTSpotIcons`、`DTCharts`。
图表组件注册名保留 `zq-line / zq-donut / zq-bars / zq-spark`。

## 六、部署步骤

1. 确认 JDK 17+ 与 MySQL 已启动。
2. 双击 `一键部署.bat`（macOS/Linux 执行 `./deploy.sh`）。
3. 浏览器打开打印出的地址：
   - 管理后台 `http://localhost:8080/admin/`
   - 商户工作台 `http://localhost:8080/merchant/`
   - 游客端 `http://localhost:8080/visitor/`（电脑手机同一地址）
   - 统一入口 `http://localhost:8080/`
4. 默认账号：admin/admin123；zhangmm、lims、liujg、wangyou、lixue 均为 123456。
5. 改了 Java 才需要 `rebuild.bat`（产物同步到 `dist/datong-cloud-server.jar`）。
6. 演示前想恢复干净数据：双击 `reset.bat` 输入 YES。
